# 11. 2D와 UI

COCOS 4는 3D 렌더링만 보는 엔진이 아닙니다. UI, 2D sprite, mask, rich text, particle-2d, tiled map 같은 기능은 실제 게임 제작에서 매우 자주 쓰입니다.

## 확인 경로

- `cocos/2d`
- `cocos/ui`
- `exports/2d.ts`
- `exports/ui.ts`
- `exports/mask.ts`
- 최근 커밋 `feat(2d): support rounded rect mask radius (#140)`

## Rounded Rect Mask 변화

최근 alpha 로그에는 2D rounded rect mask radius 지원이 들어왔습니다. 이것은 작은 기능처럼 보이지만 UI 품질에는 중요합니다. 카드, 대화창, 버튼, 패널이 모두 직각만 가능하면 시각적으로 제한이 큽니다.

실습에서는 `git show 5c99570616`을 통해 다음을 봅니다.

- 어떤 UI/2D 컴포넌트가 변경되었는가.
- mask radius가 어떤 property로 표현되는가.
- 렌더링 assembler나 material에 어떤 영향이 있는가.

## UI 검증 기준

UI는 “보인다”만으로 충분하지 않습니다.

- 텍스트가 넘치지 않는가.
- 버튼 클릭 영역이 시각 영역과 일치하는가.
- 스크롤이 다른 패널에 가려지지 않는가.
- 해상도와 aspect ratio가 바뀌어도 layout이 유지되는가.
- mask와 clipping이 실제 runtime에서도 적용되는가.

## AI 제작과의 연결

게임 제작 에이전트 UI에서 가장 중요한 것은 사람이 실제로 같이 일할 수 있는 흐름입니다. 툴 호출과 서브에이전트 활동이 별도 카드로만 쌓이면 대화 흐름을 놓치기 쉽습니다. 따라서 UI는 시간순 로그와 조작 가능 상태를 분리하지 않고, 사람이 판단할 증거를 자연스럽게 보여줘야 합니다.
